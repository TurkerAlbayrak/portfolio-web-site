# Türker Albayrak Portfolio

Sade, statik kişisel portfolio sitesi. Vercel üzerinde doğrudan root klasörden yayınlanabilir.

## Dosyalar

- `index.html`: Sayfa içeriği
- `styles.css`: Tüm görsel stil

## Vercel

Vercel'de yeni proje oluştururken bu klasörü seçmek yeterli. Build komutu gerekmez; output root dizindir.
